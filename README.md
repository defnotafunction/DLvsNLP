# Deep Learning Architectures vs. NLP
- The purpose of this research project is to examine the limits, biases, and abilities of deep learning architectures when it comes to natural language processing tasks like text generation and reasoning.

## Architectures
- MLP (Multilayer Perceptron)
- RNN (Recurrent Neural Network)
- LSTM (Long Short Term Memory Network)
- CNN (Convolutional Neural Network)
- TNN (Transformer Neural Network / Transformer)

## Benchmarks
- SQuAD (EM and F1 Score)
- Human-likeness Evaluation (Score determined by discriminator Model)

## Datasets
- SQuAD
- W.I.P
